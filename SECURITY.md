# Security

This is a local desktop application; do not expose its local service through a public proxy. Treat library exports and logs as private because URLs and machine paths may appear in them. This project does not provide encrypted local storage.

Report vulnerabilities through this repository's GitHub **Security → Report a vulnerability** feature when the maintainer enables private reporting. If unavailable, contact the maintainer through the linked Automora Labs website to arrange a private report. Do not post secrets or personal backups in public issues.

Include version, affected component, impact and a minimal reproduction using synthetic data. No response-time SLA or independent security certification is claimed.
