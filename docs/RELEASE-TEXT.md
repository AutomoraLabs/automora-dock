Automora Dock 0.4.0 is a local Windows bookmark manager and compact launcher for multiple Chrome profiles.

### Included

- Profile-aware bookmark imports and launching.
- Arranged pinned groups, shortcut folders, workspaces and PC-folder shortcuts.
- Light/dark/system appearance and subtle doodle themes.
- Full library + PC-folder JSON backup and restore.
- Separate manager/launcher shortcuts and icons.
- Optional sign-in startup and a Windows-controlled taskbar pin request.
- Startup snapshot bootstrap and a bounded local icon cache.

### Requirements

Windows 10/11 x64, .NET Framework 4.8 and Chrome for Chrome-profile launching. Node.js is bundled. WebView2 is required; Setup can install it if missing (internet required for that prerequisite).

### Download

Use the attached `AutomoraDock-Setup-0.4.0-x64.exe` and verify it against the attached SHA256 checksum. The installer is unsigned, so Windows may display a reputation warning. Taskbar pinning requires Windows permission where supported; a manual shortcut fallback is available. Windows sign-in startup timing varies by PC.
