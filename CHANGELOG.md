# Changelog

## 0.4.0 — 2026-10-29

- Automora Dock branding with separate manager/launcher icons.
- Profile-aware pins, grouped launcher, shortcut folders and workspace mosaics.
- Shared PC-folder management and full library/folder backup/restore.
- Independent manager list/grid and compact launcher grid.
- Windows pin status/request flow, sign-in startup and per-user installer with two desktop shortcuts.
- Startup snapshot bootstrap, bounded local icon cache and delayed manager prewarm.
- Open-source package with portable build paths, screenshots and CI.
